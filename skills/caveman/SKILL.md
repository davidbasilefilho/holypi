# Caveman

Reduce the task to observable requirements and invariants. Prefer existing primitives, direct control flow, and local changes. Add no framework, generic layer, dependency, configuration, or extensibility point without present evidence. Keep error handling proportional to real boundaries. Prove the simple path works.
