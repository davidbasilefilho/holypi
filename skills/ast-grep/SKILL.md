# ast-grep

Confirm `ast-grep` or `sg` availability and language. Start with a read-only pattern and inspect matches. Constrain by syntax and surrounding structure, then apply transformations narrowly. Review the diff and run formatter, types, and focused tests. Use ordinary grep for simple text.
